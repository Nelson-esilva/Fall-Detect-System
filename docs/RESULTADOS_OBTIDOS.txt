RESULTADOS OBTIDOS

O projeto alcançou resultados significativos na implementação de um sistema automatizado de detecção de quedas utilizando visão computacional e inteligência artificial. Foi desenvolvida com sucesso uma arquitetura híbrida de Deep Learning combinando CNN (MobileNetV2) e LSTM para análise temporal de sequências de vídeo. O modelo processa sequências de 20 frames em resolução 224x224 pixels, utilizando Transfer Learning para extrair características visuais e uma camada LSTM de 64 unidades para identificar padrões de movimento anormais característicos de quedas.

A escolha da MobileNetV2 como extrator de características baseou-se em sua eficiência computacional e baixa latência, essenciais para aplicações em tempo real. A arquitetura implementada utiliza TimeDistributed para aplicar a CNN em cada frame individualmente, gerando vetores de características de 1280 dimensões por frame, que são posteriormente analisados pela LSTM para capturar a dinâmica temporal do movimento.

Foi implementado um pipeline completo de processamento de dados (ETL) que processa automaticamente o dataset UR Fall Detection, convertendo sequências de imagens PNG em vídeos normalizados AVI a 30fps e organizando-os em classes binárias (Queda/Normal). O sistema inclui scripts modulares para coleta de dados via webcam (`collect_videos.py`), preparação automatizada de datasets (`prepare_ur_fall.py`) e treinamento do modelo com validação cruzada estratificada (`train_model.py`).

A arquitetura implementada utiliza técnicas avançadas de regularização, incluindo Dropout de 0.5 na camada de saída da LSTM e callbacks de Early Stopping com paciência de 5 épocas para evitar overfitting. O modelo foi treinado com otimizador Adam, função de perda binary_crossentropy e métrica de acurácia, utilizando divisão 80/20 para treino e teste com estratificação para garantir balanceamento das classes.

O sistema de detecção em tempo real foi desenvolvido e testado (`main.py`), processando frames de vídeo em tempo real através de webcam, mantendo um buffer circular de 20 frames para análise sequencial e exibindo alertas visuais em vermelho quando uma queda é detectada com confiança acima de 50%. A implementação utiliza OpenCV para captura e processamento de vídeo e TensorFlow/Keras para inferência neural, demonstrando viabilidade técnica para aplicação prática com processamento em tempo real.

Em relação ao objetivo de implementar algoritmos de visão computacional, foram desenvolvidos algoritmos utilizando MobileNetV2 pré-treinada no ImageNet com pesos congelados, permitindo aproveitamento de conhecimento pré-existente e reduzindo o tempo de treinamento. O modelo híbrido CNN-LSTM foi completamente implementado para classificação de movimentos, diferenciando quedas de atividades diárias normais (ADL) através da análise de padrões temporais.

O sistema foi validado com o dataset UR Fall Detection, que contém 30 sequências de quedas e 40 sequências de atividades diárias normais, totalizando 70 sequências processadas e convertidas em múltiplas amostras de treinamento através de técnica de sliding window com passo de 10 frames, aumentando significativamente a quantidade de dados disponíveis. O processamento demonstrou capacidade de lidar com diferentes condições de iluminação e posicionamento de câmeras presentes no dataset.

A arquitetura modular desenvolvida separa claramente a lógica do modelo (`src/model.py`), pré-processamento de dados e treinamento, facilitando manutenção e extensão. Esta estrutura permite fácil extensão para desenvolvimento de aplicativo móvel em Flutter ou React Native para notificar cuidadores em tempo real, bem como integração com módulos de hardware como ESP32/Raspberry Pi para alertas sonoros locais.

Foram superados desafios técnicos significativos, incluindo incompatibilidades de versões do TensorFlow no ambiente Windows, resolvidas através de limpeza completa do ambiente virtual e reinstalação controlada de dependências. A heterogeneidade dos dados brutos do dataset foi contornada através de implementação de busca recursiva que torna o sistema agnóstico à estrutura de pastas.

O projeto estabeleceu a fundação técnica completa necessária para reduzir o tempo de socorro em casos de quedas, com sistema funcional de detecção em tempo real, pipeline automatizado de dados e arquitetura neural validada. Os resultados demonstram viabilidade técnica e científica para aplicação prática em ambientes residenciais e institucionais de cuidado a idosos e pessoas com mobilidade reduzida.
